Vesu Earn implementation audit

Reviewed 2026-09-06 against the four Limen-style assurance recommendations.

Outcome

Source and verification tooling are internally ready.

The route is not ready for deployment admission or user funds. The manifest remains pending, and the machine gate correctly exits non-zero.
